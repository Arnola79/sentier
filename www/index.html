    Points de passage

      Envoyer sur la Fenix 6
      1. Sur téléphone (app) : « Télécharger le GPX » ouvre le menu de partage, enregistre le fichier (Fichiers ou Drive), puis importe-le dans Garmin Connect depuis un navigateur.
      2. Garmin Connect (web) : Entraînement, Parcours, Importer, choisis le .gpx, puis « Envoyer vers l'appareil ». La montre le reçoit à la prochaine synchronisation.
      3. USB : copie le .gpx dans le dossier Garmin/NewFiles de la montre. Si le parcours n'apparaît pas, passe par Garmin Connect.
      4. Sur la montre : activité Rando, Navigation, Parcours.
